# Security policy

## Supported versions

The current `main` release line receives security fixes. Older releases are
supported only when their release notes explicitly state that support window.

## Reporting a vulnerability

Do not create a public issue for suspected vulnerabilities or include secrets,
exploit details, production URLs, backups or personal data in public reports.
Send a private report to [joshua@pondsec.com](mailto:joshua@pondsec.com) with a
clear reproduction, affected version and impact assessment.

We aim to acknowledge reports within 3 business days, provide an initial
assessment within 10 business days, and coordinate disclosure after a fix or
mitigation is available. These are response targets, not a guarantee of a fixed
release time.

## Scope

Authentication, authorization, session handling, CSRF, inventory links, proxy
behaviour, uploads/imports, backup/restore and signed updates are in scope.
Third-party services should also be reported privately when their use exposes an
Inventory Pro installation.
